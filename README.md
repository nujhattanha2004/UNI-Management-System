# University Management System 🎓

## 📌 About the Project

The University Management System is a frontend-based website designed to provide a simple and user-friendly interface for managing university-related information.

This project was developed as part of an academic project to practice HTML, CSS, and Bootstrap.

## ✨ Features

- 🏠 Home Page
- 👨‍🎓 Students Page
- 👩‍🏫 Teachers Page
- 📚 Courses Page
- 🏢 Departments Page
- 🔐 Login Page
- 📝 Registration Page
- 📩 Contact Page
- 📱 Responsive navigation using Bootstrap

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

## 📂 Project Pages

- `index.html` — Home page
- `students.html` — Students page
- `teachers.html` — Teachers page
- `courses.html` — Courses page
- `department.html` — Departments page
- `login.html` — Login page
- `register.html` — Registration page
- `contact.html` — Contact page
